📖 Panduan Pemakaian

💰 Expense Tracker

  1. Isi judul, kategori, jumlah (harus lebih dari 0), tipe, dan tanggal.
  2. Klik Tambah Transaksi. Ringkasan saldo akan diperbarui.
  3. Gunakan kolom cari, filter tipe/kategori, dan urutan untuk menyaring daftar.
  4. Ikon ✎ untuk mengubah, ikon 🗑 untuk menghapus (ada konfirmasi).
Buka Expense Tracker →

🔖 Bookmark Manager

  1. Isi nama, URL (wajib diawali http:// atau https://), dan kategori.
  2. Klik nama bookmark untuk membuka tautan di tab baru.
  3. Cari berdasarkan nama, URL, atau kategori, lalu urutkan sesuai kebutuhan.
Buka Bookmark Manager →

🧠 Quiz App

  1. Klik Mulai Kuis, lalu pilih satu jawaban per soal.
  2. Skor dihitung otomatis. Skor tertinggi tersimpan di browser.
  3. Klik Main Lagi untuk mengulang.
